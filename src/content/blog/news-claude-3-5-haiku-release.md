Anthropic has officially launched **Claude 3.5 Haiku**, the compact powerhouse in the Claude 3.5 model family. Designed as the direct successor to Claude 3 Haiku, this latest iteration sets a new efficiency benchmark for lightweight enterprise AI.

## Intelligence Matching Previous Flagships

In internal and third-party evaluations, Claude 3.5 Haiku matches or exceeds the scores of **Claude 3 Opus**—Anthropic’s top-tier model from early 2024—across coding, mathematics, and complex reasoning tasks, while executing at a fraction of the token cost and inference latency.

| Benchmark | Claude 3 Haiku | Claude 3 Opus | Claude 3.5 Haiku |
| :--- | :--- | :--- | :--- |
| **SWE-bench Verified** | 8.8% | 22.0% | **40.6%** |
| **HumanEval (Python)** | 75.9% | 84.9% | **88.9%** |
| **MMLU (Undergrad)** | 75.2% | 86.8% | **85.3%** |

## Best Use Cases

1. **Agentic Code Assistants**: Rapidly parsing files, applying unified diffs, and verifying syntax without slowing down developer velocity.
2. **Customer-Facing Chatbots**: Instant streaming responses with human-grade nuanced conversational ability.
3. **High-Throughput Extraction**: Processing thousands of structured JSON extractions per hour at minimal operational cost.

Claude 3.5 Haiku is accessible through the Anthropic Messages API, the Amazon Bedrock console, and Google Cloud Vertex AI.
